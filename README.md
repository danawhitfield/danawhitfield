## What I'm working on

Every provider on WorkingMomRx gets one score out of 100 from six weighted factors: time to first dose (22%), flat pricing (20%), no-video intake (18%), nationwide access (15%), both molecules on one plan (13%) and an easy off-ramp (12%). The same rubric runs for everyone.
